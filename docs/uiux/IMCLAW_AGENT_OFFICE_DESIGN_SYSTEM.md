# imClaw Agent Office & Command Centre — Design System

## 1. Visual Language & Color Tokens

- **Space / Canvas Background:** `--bg-space: #07090e`
- **Surface Panels:** `--bg-panel: #0d1117`, `--bg-card: #161b22`
- **Borders & Dividers:** `--border: #30363d`, `--border-bright: #58a6ff`
- **Character Accent (Lobster Red):** `--lobster-red: #ff3344`, `--lobster-crimson: #c71f37`
- **Emissive Glow:** `rgba(255, 51, 68, 0.45)`
- **Intelligence Accents (Cyan):** `--cyan-bright: #00e5ff`, `rgba(0, 229, 255, 0.4)`
- **Operational Status:**
  - Online / Idle: `--green-online: #10b981`
  - Running / In Progress: `--cyan-bright: #00e5ff`
  - Blocked / Approvals: `--amber-alert: #f59e0b`
  - Error: `--lobster-red: #ff3344`

## 2. Typography

- **UI Elements:** System Sans stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto`)
- **Code & Identifiers:** Monospace (`ui-monospace, "SF Mono", Menlo, Consolas`)
